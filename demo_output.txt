------------------------------------------------------------------------------
VOICEHAUL - long-horizon evaluation for empathic voice agents
------------------------------------------------------------------------------
suite      : 5 personas x 30 episodes x 40 turns = 1,200 scored turns
personas   : distressed_billing, hostile_escalation, confused_elderly, grieving_claim, cautious_optimist
guarantees : no network, no API key, deterministic under a fixed seed

------------------------------------------------------------------------------
[4] MIMICRY VS REGULATION
------------------------------------------------------------------------------
mimicry    = corr(agent vocal energy, user arousal)   -> sounds attuned
regulation = negative affect removed per turn (x100)  -> actually helps

agent             mimicry r      regulation       MAI
mirror                +0.16            2.61      2.29
flat_cheerful         -0.00           -1.37     -1.37
drifter               -0.83            0.44      0.44
calibrated            -0.56            3.80      3.80
oracle                -0.54            3.82      3.82

  the mirror tracks the user (+0.16); the calibrated policy moves
  against them (-0.56) and removes 46% more distress per turn.
  MAI ranking is stable for k in [1, 4] (1 distinct ordering).

------------------------------------------------------------------------------
[5] CORRUPTED FEEDBACK: WHEN THE CHANNEL ITSELF IS WRONG
------------------------------------------------------------------------------
A share of user requests reach the model as the opposite instruction
(ASR error, or an adversarial user). The user still expects the original.

agent            clean FUR@10   20% corrupt   40% corrupt        drop
mirror                   1.00          0.85          0.68      -32.4p
flat_cheerful            0.00          0.00          0.00        0.0p
drifter                  0.80          0.77          0.78       -2.2p
calibrated               1.00          0.85          0.70      -30.4p

  the agents that listen best degrade most: perfect compliance with a
  corrupted channel is itself a failure mode, and it is invisible to
  any suite whose feedback channel is assumed clean.

------------------------------------------------------------------------------
[6] FAILURE-ONSET LOCALIZATION
------------------------------------------------------------------------------
A regression is injected at a known turn: the model loses its
conditioning and reverts to a generic upbeat persona. The task is to
name that turn from the conversation alone. Cheap deterministic
diagnostics propose candidates; counterfactual replay confirms cause.

fault severity conversations       top-1       top-3    median error
1.00                      30      100.0%      100.0%        +0 turns
0.70                      30       93.3%       96.7%        +0 turns
0.50                      30       93.3%       93.3%        +0 turns
0.35                      30       86.7%       90.0%        +0 turns

  false positives on healthy runs : 0.0%  (n=30)
  severity 1.00 is a full reversion; 0.35 blends the degraded persona
  into the model's own policy, which is the realistic case. Accuracy
  should always be reported against it, never as a single number.

  example: persona=distressed_billing  true fault turn=20  predicted=20
  ranked candidates: [20, 21, 22, 23, 24]

------------------------------------------------------------------------------
[7] HOW MANY CONVERSATIONS BEFORE A REGRESSION IS VISIBLE?
------------------------------------------------------------------------------
Human ratings are both the ground truth and the budget line. Between-
conversation spread is measured from this suite; rater noise is set to
0.9 Likert points. Two-sample, alpha=0.05, power=0.80.

  measured between-conversation sd : 0.40 Likert points

raters / conversation           N=30       N=100       N=300
1                               0.71        0.39        0.22
3                               0.47        0.26        0.15
5                               0.41        0.22        0.13
  (cells are the smallest true regression, in Likert points, that the
   suite can detect at 80% power)

  a 30-conversation suite with 3 raters cannot see anything smaller
  than 0.47 points; catching a 0.20-point regression needs N = 168.
